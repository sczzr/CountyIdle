# 功能卡：仓储三源产出与入库分层

## 功能信息

- 功能名：仓储三源产出与入库分层
- 优先级：P1
- 目标版本：2026.03
- 关联系统：仓储与资源链、外务历练、手动制造

## 目标与用户收益

- 目标：让仓储明确区分“经营产出 / 外务收获 / 手动作成品”，并提供可见入库流程。
- 玩家可感知收益（10 分钟内）：能一眼看出产出来自哪条线，外务收获不再默默混入库存，手作成品有明确入库动作。

## 实现范围

- 包含：三源产出归档、外务行囊/工坊成品暂存、入库动作与仓储卷摘要提示。
- 不包含：新增高阶材料、改变产出数值、重做外务战斗或制造配方系统。

## 实现拆解

1. 在系统规格中明确三源产出分层与入库规则。
2. 增加外务行囊与工坊成品暂存的库存字段与转入仓库动作。
3. 仓储卷状态区展示三源摘要与入库按钮。

## 验收标准（可测试）

- [ ] 时辰结算的经营产出直接计入宗门仓库，并标注来源。
- [ ] 外务历练收获进入行囊，未入库前不参与建造/消耗。
- [ ] 手动制造的成品进入“工坊成品”暂存，可一键入库。
- [ ] 仓储卷状态区可看到三源摘要，并可触发入库动作。

## 风险与回滚

- 风险：新增暂存层与入库动作可能让玩家误以为产出消失，或导致 UI 入口不足。
- 回滚方式：回退到“所有产出直接进仓库”的旧流程，并保留来源日志占位。

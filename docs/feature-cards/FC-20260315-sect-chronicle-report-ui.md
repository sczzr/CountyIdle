# 功能卡：宗门见闻卷与宗务报表卷 UI 原型

## 功能信息

- 功能名：宗门见闻卷与宗务报表卷 UI 原型
- 优先级：`P1`
- 目标版本：`2026-03-15 UI 原型`
- 关联系统：`DL-003`、`SectChronicleRules`、`GameState`、`EventLogPanel`、`PopupPanelBase`

## 目标与用户收益

- 目标：把右侧“天衍峰记事”的摘要能力扩展为可展开的卷册 UI，让玩家能在同一套界面里查看实时见闻告警、近期札记与宗门关键经营报表，不再依赖隐藏兼容页签或静态占位文案。
- 玩家可感知收益（10 分钟内）：点击右侧纪事入口即可打开新卷册，在“见闻 / 报表”两页之间切换，快速读到当前山门警讯、按类别筛读近时日志、人口/仓储/研修/外务的实时快照，以及最近几次时辰结算与季度/年度摘要。

## 实现范围

- 包含：
  - 新增一个卷册类弹窗 `SectChroniclePanel`
  - 右侧“天衍峰记事”增加展开入口，打开卷册
  - 卷册包含“宗门见闻”“宗务报表”两个页签
  - 数据接入 `SectChronicleRules`、`GameState` 当前快照与主界面近期日志队列
  - 运行时记录最近若干次时辰结算快照，并在报表页展示趋势摘要
  - 见闻页支持按 `全卷 / 政务 / 库藏 / 外务 / 留档` 分类筛读近时札记
  - 报表页补季度与年度摘要卡片
  - 接入现有弹窗排他规则与 `Esc` 收卷
- 不包含：
  - 不恢复历史 `Event / Report` 地图页签
  - 不新增新的结算系统、长周期数据库或事件分类存档
  - 不改小时结算顺序与 `GameLoop` 主链

## 实现拆解

1. 补齐功能卡与文档口径，明确“右栏摘要 + 展卷细读”的新 UI 方向。
2. 新增 `SectChroniclePanel` 场景与脚本，完成两页式卷册原型。
3. 在 `Main` 中接入创建、打开、刷新、排他关闭与快捷键门禁。
4. 用当前运行数据填充告警、日志与报表卡片，替换纯静态占位认知。

## 验收标准（可测试）

- [ ] 主界面右侧“天衍峰记事”存在可点击的展开入口，能打开新卷册。
- [ ] 卷册可在“宗门见闻 / 宗务报表”两页切换，并显示实时 `GameState` 派生内容。
- [ ] 见闻页可按分类筛读近时札记，帮助宗主快速收束到对应问题域。
- [ ] 报表页可展示最近几次时辰结算的关键涨跌回看，而不只是单帧静态快照。
- [ ] 报表页补有季度与年度摘要卡片，用于快速判断中程走势。
- [ ] 卷册打开时会遵守现有卷册排他规则，`Esc` 可关闭，打开期间全局快捷键让行。
- [ ] `Event / Report` 历史兼容页签仍保持隐藏兼容状态，不重新混入主地图页签链。

## 风险与回滚

- 风险：如果把入口重新挂回地图页签，容易与 `DL-081` 的双地图入口裁定冲突；如果卷册数据直接写在 `Main.cs`，后续会继续堆积 UI 文案逻辑。
- 回滚方式：移除新增的 `SectChroniclePanel` 与右栏展开入口，恢复为仅保留右侧摘要版“天衍峰记事”。

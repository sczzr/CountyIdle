# 功能卡（Feature Card）

## 功能信息

- 功能名：印章确认按钮可复用控件
- 优先级：`P1`
- 目标版本：`2026.03`
- 关联系统：UI 组件 / 机宜卷

## 目标与用户收益

- 目标：抽出“确认/收录”按钮为独立可复用控件，统一悬停反馈。
- 玩家可感知收益（10 分钟内）：多个卷册里的确认按钮有一致的放大、旋转与朱红填充反馈。

## 实现范围

- 包含：
  - 新增可复用组件场景 `SealConfirmButton` 与对应 GDScript 动效脚本。
  - `SettingsPanel` 右下角确认按钮替换为新组件，保留自定义尺寸。
- 不包含：
  - 全局替换所有按钮（仅首轮落地 SettingsPanel）。
  - 重新设计按钮文案或业务逻辑。

## 实现拆解

1. 新增 `SealConfirmButton` 组件场景与动效脚本（悬停放大/旋转/红底填充）。
2. 替换 `SettingsPanel` 的确认按钮为该组件并校验样式。
3. 保持 `SettingsPanelVisualFx` 只做字体/排版，不重复覆盖组件动效。

## 验收标准（可测试）

- [ ] `SealConfirmButton` 组件可被实例化并可调整尺寸。
- [ ] 悬停时出现放大、轻微旋转与朱红填充效果，离开后复位。
- [ ] `SettingsPanel` 使用新组件且显示正常。

## 风险与回滚

- 风险：不同分辨率下的 pivot/缩放导致轻微偏移。
- 回滚方式：恢复为原 `SealButton` 实例并移除组件脚本引用。

# 功能卡：弟子谱 UI 布局对齐参考版

## 功能信息

- 功能名：弟子谱 UI 布局对齐参考版
- 优先级：P1
- 目标版本：2026.03
- 关联系统：弟子谱 UI、UI 表现层（GDScript）

## 目标与用户收益

- 目标：将 DisciplePanel 的布局调整为“左侧名册 + 右侧详情卡（头像/指令）+ 双列指标 + 卷尾详录”的结构，与 AI Studio 参考图一致。
- 玩家可感知收益（10 分钟内）：信息区块更清晰，弟子指令与属性一屏可读。

## 实现范围

- 包含：DisciplePanel.tscn 布局重排、节点路径同步（DisciplePanel.cs / DisciplePanelVisualFx.gd）、卷尾详录区块合并。
- 不包含：弟子生成规则、指令逻辑、数值计算与存档结构调整。

## 实现拆解

1. 调整 DisciplePanel.tscn 布局为参考结构（侧栏 + 右侧滚动详情 + 双列卡 + 卷尾详录）。
2. 同步 C# / GDScript 的节点绑定路径与样式调用。
3. 复核雷达图、筛选与指令按钮交互仍可用。

## 验收标准（可测试）

- [ ] 弟子谱弹窗布局与参考图一致，左侧名册/右侧详情分区清晰。
- [ ] 头像信息与指令按钮同卡展示，且指令按钮可点击。
- [ ] 雷达图与六维指标正常显示，卷尾详录可滚动查看。
- [ ] 无节点路径报错或 UI 崩溃。

## 风险与回滚

- 风险：节点路径调整导致绑定失败或样式错位。
- 回滚方式：回退本次 UI 布局与节点路径改动。

# 功能卡：文明式营建卷（城建建造）

- 功能名：文明式营建卷（城建建造）
- 任务 ID：`DL-090`
- 目标（玩家价值）：让建造入口像文明五的“城市建造”一样清晰可挑选、可比较、可排队，玩家能理解建造收益与成本，并把建造与院域坊局/宗门经营联动起来。
- 飞轮环节：产业涌现 → 人口繁衍 → 反哺宗门
- 依赖：`IndustrySystem`、`CountyTownMapViewSystem`、`MainSectTileInspector`、右栏营建清单

## 交付范围

- 新增“营建卷/城建建造”独立面板入口，可从右栏营建清单或左侧地块检视器进入；
- 面板布局采用“建筑列表 + 详情对比 + 建造队列/进度”三段式结构，支持类别筛选与说明文案；
- 建造动作与选中地块绑定，保留“院域坊局”语义与建筑显影反馈。

## 非目标

- 不引入纯建筑摆放玩法；
- 不改动非建造系统的核心公式与存档结构（除非后续接入建造进度，需单独提案）。

## 完成标准（DoD）

- [ ] 能从主界面进入“营建卷”，并在卷内完成建筑选择与建造（已实现，待验证）；
- [ ] 建筑条目展示成本、收益摘要与依赖提示（已实现，待验证）；
- [ ] 建造结果与地块/坊局联动，并能在山门图显影（沿用既有建造落点链路，待验证）；
- [ ] 若接入建造进度：支持队列/进度显示并在小时结算推进；
- [ ] `dotnet build .\Finally.sln` 通过。

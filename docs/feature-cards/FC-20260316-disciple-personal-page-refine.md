# 功能卡：弟子个人页详录分组补强

## 功能信息

- 功能名：弟子个人页详录分组补强
- 优先级：`P1`
- 目标版本：`2026-03-16 UI 强化`
- 关联系统：`DL-043`、`DisciplePanel`、`DiscipleRosterSystem`、`docs/16_cultivator_classification_design.md`

## 目标与用户收益

- 目标：把弟子个人页的“卷中详录”整理成更清晰的分组，并补齐概览线与修为/气海/战力/灵根摘要，减少长卷信息的阅读负担。
- 玩家可感知收益（10 分钟内）：在弟子谱中选中弟子时，档案段落层次更清楚，重要信息（身份/修为/功法/技艺与进度评定）能更快读到。

## 实现范围

- 包含：
  - 个人页概览线补入 `修为`，保持 `身份 → 修为 → 功法 → 技艺` 顺序。
  - 卷中详录按“身份与籍录 / 修为与功法 / 性情与指标”三段分组。
  - 卷中详录新增 `修为进度 / 气海蓄量 / 战力评定 / 灵根摘要` 文案。
- 不包含：
  - 不新增存档字段或改动 `GameState`。
  - 不改数值公式与小时结算。
  - 不新增弟子实体化 AI 或装备/功法系统。

## 实现拆解

1. 在 `DisciplePanel.cs` 调整个人页概览行与卷中详录文本组织。
2. 用现有派生口径补齐修为/气海/战力/灵根摘要，不新增模型字段。
3. 回写功能卡与台账记录。

## 验收标准（可测试）

- [x] 个人页概览行显示 `身份 / 修为 / 功法 / 技艺`。
- [x] 卷中详录出现三段分组标题与新增进度评定信息。
- [ ] 不影响名册筛选、排序与弟子定位链路。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：详录信息增多可能拉长滚动距离，影响阅读节奏。
- 回滚方式：还原详录分组与新增字段，恢复为单列表展示。

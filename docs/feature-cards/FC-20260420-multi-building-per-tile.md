# 功能卡：院域同地块多建筑落位（营建卷二期）

## 功能信息

- 功能名：院域同地块多建筑落位（营建卷二期）
- 关联系统：`DL-047`、`DL-090`
- 优先级：`P1`
- 目标版本：2026-04-20
- 主要入口：`CountyTownMapViewSystem`、`MainBuildingPlacement`、`ConstructionPanel`

## 目标与用户收益

- 目标：把当前仍停留在“`1` 地块 = `1` 建筑”的落点链，补齐到既有规格里承诺的“同地块 `2~3` 建筑槽位”。
- 玩家可感知收益（10 分钟内）：在山门图选中同一块院域后，可以像文明城市那样继续往同一地块追加不同建筑，而不是被迫每格只落一个。

## 实现范围

- 包含：
  - 同地块允许落入多种建筑，直到达到 `BuildSlotCount` 上限；
  - 营建完工后的落点持久化继续写入 `GameState.TownBuildingPlacements`；
  - 院域营建卷、营建卷详情、地块摘要统一显示同格多建筑列表；
  - 地图显影支持同格多建筑偏移显示，避免多个建筑完全重叠。
- 不包含：
  - 完整拖拽式地块内建筑编辑器；
  - 建筑升级树、拆除回收、地块内手工排序；
  - 小时结算层面的共享灵气正式生效计算。

## 实现拆解

1. 放宽建筑落点注册规则，允许同地块保留多条 `TownBuildingPlacement`。
2. 将地块可建校验改为“槽位是否已满”，而不是“该格是否已被任何建筑占用”。
3. 将锚点选中视为“已选中该地块”，允许玩家点到已有建筑后继续同格营建。
4. 同步修正地图显影与地块摘要，让多建筑状态可被直接看见。

## 完成标准（DoD）

- [ ] 同一地块可依次落入多种建筑，直到达到 `BuildSlotCount` 上限。
- [ ] 选中已有建筑锚点时，营建卷仍可继续对该地块追加建造。
- [ ] 同地块多个建筑在山门图上不会完全重叠到无法辨认。
- [ ] 存档 / 读档后，同地块多建筑落位仍能正确复原。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：若只放宽存档落点、不修改地图显影与选中逻辑，玩家仍会误以为同地块只能有一个建筑。
- 回滚方式：保留文档与槽位规格，暂时恢复单格单建筑写入，但不得回退 `DL-047` 对“同地块多建筑坊局”的主规格表述。

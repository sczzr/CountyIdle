# 功能卡：弟子谱双页拆分（宗门大谱 / 命谱详情）

## 功能信息

- 功能名：弟子谱双页拆分（宗门大谱 / 命谱详情）
- 优先级：P1
- 目标版本：VNext
- 关联系统：弟子谱 / 宗门组织谱 / `DisciplePanel` / `SectOrganizationPanel`

## 目标与用户收益

- 目标：将现有弟子谱的“左列表 + 右详情”拆成两个全屏页面，形成宏观组织谱与单人命谱焦点页。
- 玩家可感知收益（10 分钟内）：层级关系更清晰、个人详情更沉浸，减少信息拥挤与视线切换。

## 实现范围

- 包含：
  - 两份全屏 HTML 原型（宗门大谱树状页 / 命谱详情焦点页）。
  - 树状页点击弟子跳转详情、详情页返回树状页的基本导航关系。
- 不包含：
  - Godot UI 的真实接入与数据绑定。
  - 玩法、结算与存档结构改动。

## 实现拆解

1. 建立宗门大谱（树状页）与命谱详情（焦点页）的 HTML 原型。
2. 补齐两页间跳转路径（树状页 -> 详情页、详情页 -> 树状页）。
3. 后续在 Godot 中拆分为两个全屏卷册/弹窗并接入真实数据（单独实施）。

## 验收标准（可测试）

- [ ] `docs/ui-prototypes/sect_tree.html` 可独立打开并展示树状族谱结构。
- [ ] `docs/ui-prototypes/character_profile.html` 可独立打开并展示角色焦点详情。
- [ ] 两页之间具备可用的跳转与返回链接。

## 风险与回滚

- 风险：仅原型阶段容易被误解为“已接入游戏 UI”。
- 回滚方式：移除 HTML 原型文件，不影响运行版。

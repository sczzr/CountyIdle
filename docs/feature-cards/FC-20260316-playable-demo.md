# 功能卡：最小可玩 Demo 目标引导

## 功能信息

- 功能名：最小可玩 Demo 目标引导（右栏试玩目标）
- 优先级：P1
- 目标版本：Demo-V1
- 任务 ID：`DL-083`
- 关联系统：主界面右栏、时辰结算、研修突破、历练结算

## 目标与用户收益

- 目标：在不改动核心结算与存档的前提下，让玩家 10 分钟内完成三条关键闭环并看见进度。
- 玩家可感知收益（10 分钟内）：知道该做什么、进度清晰可追踪、完成后有明确达成感。

## 实现范围

- 包含：右栏试玩目标面板、目标完成计数、基于现有 `GameState` 的进度提示与完成态展示。
- 不包含：强制引导、文本教程、核心数值/结算规则改动、存档格式改动。

## 实现拆解

1. 在右栏 `EventLogPanel` 增加试玩目标面板结构。
2. 新增 `DemoPanel` 脚本，基于 `GameState` 刷新三项目标状态与完成计数。
3. 主界面绑定 demo 面板刷新（随 `OnStateChanged` 更新）。

## 验收标准（可测试）

- [x] 右栏出现“试玩目标”面板并显示 3 条目标与完成计数。
- [x] 时辰结算 / 研修突破 / 历练结算进度随 `GameState` 刷新。
- [x] 目标完成后保持完成态展示。
- [x] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：右栏空间被挤压导致日志显示区域变小。
- 回滚方式：移除 `DemoBox` 节点与 `DemoPanel` 脚本绑定，恢复原右栏布局。

# 功能卡：弟子谱详情全信息展示

## 功能信息

- 功能名：弟子谱详情全信息展示
- 优先级：`P1`
- 目标版本：`2026-03-15 UI 强化`
- 关联系统：`DL-043`、`DisciplePanel`、`DiscipleRosterSystem`、`docs/16_cultivator_classification_design.md`

## 目标与用户收益

- 目标：让弟子谱右侧详情不再只显示部分属性摘要，而是能够完整读到当前派生出的弟子信息，包括身份、功法、技艺、职司、状态与全部已生成属性值。
- 玩家可感知收益（10 分钟内）：打开弟子谱后，选中任一弟子即可看到完整档案，不必在“属性块 / 批注 / 特征”之间自行拼凑信息。

## 实现范围

- 包含：
  - 右侧详情顶部补入 `身份 / 功法 / 技艺`
  - 指标区补齐 `战力 / 执行 / 贡献`
  - 新增“卷尾详录”区，展示当前 `DiscipleProfile` 的完整信息
  - 文档同步到现行 UI 口径
- 不包含：
  - 不改存档结构
  - 不引入弟子实体化 AI
  - 不改小时结算与数值公式

## 实现拆解

1. 复核 `DiscipleProfile` 现有字段与弟子谱现行缺口。
2. 扩展 `DisciplePanel.tscn` 右侧详情布局，补齐缺失指标与卷尾详录区。
3. 在 `DisciplePanel.cs` 中整理身份 / 功法 / 技艺派生文案，并写入完整档案文本。
4. 回写专题文档，确保 UI 字段说明与运行版一致。

## 验收标准（可测试）

- [ ] 选中弟子后，详情区显式显示 `身份 / 功法 / 技艺`。
- [ ] 指标区显式显示 `战力 / 执行 / 贡献`，不再只保留 6 项。
- [ ] 卷尾详录区能完整展示当前弟子的全部派生信息。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：若把技术字段直接裸露为内部命名，会破坏当前宗门语义；若右侧版面堆叠过多，可能影响卷册可读性。
- 回滚方式：移除新增指标块与卷尾详录区，恢复到旧版详情布局，同时保留弟子谱已有筛选、树状名册与地图联动。

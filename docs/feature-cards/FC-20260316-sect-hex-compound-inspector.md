# 功能卡：地块建筑列表（左侧检视器）

## 功能信息

- 功能名：地块建筑列表（左侧检视器）
- 优先级：P1
- 目标版本：Demo-V1
- 关联系统：`TownMapSelectionSummary`、`CountyTownMapViewSystem`、`MainSectTileInspector`

## 目标与用户收益

- 目标：在左侧地块检视器中直接看到“该地块当前有哪些建筑/坊局”。
- 玩家可感知收益（10 分钟内）：选中地块即可看见当前建筑列表，减少“建了却找不到”的困惑。

## 实现范围

- 包含：锚点场所显示已落成建筑名；普通院域显示坊位规划列表。
- 不包含：新增建筑类型、改动建造成本/结算、调整坊局规则。

## 实现拆解

1. 扩展 `TownMapSelectionSummary` 增加建筑列表字段。
2. 生成锚点/院域的建筑列表摘要。
3. 左侧检视器新增显示区域并绑定刷新。

## 验收标准（可测试）

- [ ] 选中锚点场所时，可显示已落成建筑名。
- [ ] 选中普通院域时，可显示坊局规划列表。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：建筑列表过长导致左侧检视器拥挤。
- 回滚方式：移除建筑列表字段与 UI 区块，恢复原检视器布局。

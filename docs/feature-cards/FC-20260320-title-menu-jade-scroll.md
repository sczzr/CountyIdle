# 功能卡：国风题屏主菜单（玉简起卷）

## 功能信息

- 功能名：国风题屏主菜单（玉简起卷）
- 优先级：`P1`
- 目标版本：2026-03-20
- 关联系统：主界面入口、设置卷、存档槽、题屏视觉表现

## 目标与用户收益

- 目标：在进入正式宗门经营前，补一套可直接进入游戏的国风标题页，用玉简主菜单承接“开始 / 读取 / 设置 / MOD / 退出”五项入口。
- 玩家可感知收益（10 分钟内）：首次启动即能看到稳定统一的修仙题屏，不再直接落入信息密集的经营主界面。

## 实现范围

- 包含：
  - 米色宣纸底、`background_2.png` 经 `background_frosted_glass.gdshader` 处理并带低频呼吸动画的山水底图与竖排诗文瀑布背景；
  - 五组可 hover 展开的玉简菜单项（玉简本体以 SVG 直显，并补轻微投影）；
  - 右下角印章落款；
  - `开始 / 读取 / 设置 / 退出` 与现有 `Main`、`SaveSlotsPanel`、`SettingsPanel` 的入口接线；
  - `MOD` 项的占位提示文案；
  - 题屏隐藏时停止诗文瀑布刷新，宣纸背景 Shader 保持轻量化。
- 不包含：
  - 独立 MOD 管理界面或模组加载逻辑；
  - 全局主题切换到整套标题页视觉；
  - 改写现有主循环、结算或存档结构。

## 实现拆解

1. 在 `docs/05_feature_inventory.md` 与 `docs/08_development_list.md` 登记“国风题屏主菜单”功能包与状态。
2. 新增 `TitleMenuOverlay`、`JadeMenuItem`、`PoemWaterfallManager` 与对应 shader/scene。
3. 将题屏作为 `Main.tscn` 的启动遮罩接入，并在进入游戏前暂停 `GameLoop`。
4. 把 `开始 / 读取 / 设置 / 退出` 对接到现有正式入口，`MOD` 暂以状态提示占位。

## 验收标准（可测试）

- [ ] 启动 `Main.tscn` 后，默认先看到题屏主菜单，而不是直接显示正式经营主界面。
- [ ] 玉简菜单项支持 hover 展开、主简抬升与题字转朱砂红。
- [ ] `开始 / 读取 / 设置 / 退出` 分别能进入正式主界面、打开存档卷、打开设置卷与退出应用。
- [ ] 题屏可阻断正式主界面的全局快捷键与时间推进，直到玩家正式入局。
- [x] `dotnet build .\Finally.sln` 通过。
- [ ] Godot 启动链路需继续排查既有 `SettingsPanelVisualFx.gd` 解析错误、`xianxia.css` 资源 UID warning 等工程问题后，再补题屏实机巡检结论。

## 风险与回滚

- 风险：若题屏遮罩与现有弹窗层级处理不当，可能出现存档卷/设置卷被盖住或题屏关闭后主界面未恢复的问题。
- 回滚方式：移除 `TitleMenuOverlay` 接线与新增资源，恢复 `Main.tscn` 直接进入正式主界面。

# 功能卡：仓储卷修仙化 UI 改版（藏宝阁）

## 功能信息

- 功能名：仓储卷修仙化 UI 改版（藏宝阁）
- 优先级：P1
- 目标版本：2026.03
- 关联系统：仓储卷 UI、`WarehousePanel`、`WarehousePanelTransition.gd`

## 目标与用户收益

- 目标：将仓储卷文案、页签与视觉风格统一为修仙世界观，并引入品阶配色体系。
- 玩家可感知收益（10 分钟内）：一眼识别“神兵/功法/丹药/天材/玉钱”分区，稀有度色阶更直观。

## 实现范围

- 包含：仓储卷页签与文案更新、品阶色彩体系接入、卡片样式与预警文案重写。
- 不包含：新增真实法宝/功法/丹药数据、仓储数值与结算规则改动。

## 实现拆解

1. 更新 `WarehousePanel.tscn` 文案与页签布局。
2. 调整 `WarehousePanel.cs` 的分类枚举、分组与品阶标注。
3. 更新 `WarehousePanelTransition.gd` 的主题与品阶色彩表现。

## 验收标准（可测试）

- [ ] 页签显示“森罗全象 / 神兵法宝 / 功法秘籍 / 丹药灵草 / 天材地宝 / 宗门玉钱”，切换生效。
- [ ] 预警文案改为“须弥芥子空间满溢”语义，容量数值样式正确。
- [ ] 资源卡片呈现天地玄黄/橙紫蓝绿的品阶色彩。
- [ ] 无节点路径报错或 UI 崩溃。

## 风险与回滚

- 风险：枚举与节点路径变更导致页签或卡片显示异常。
- 回滚方式：回退本次 UI 与脚本文案/样式改动。

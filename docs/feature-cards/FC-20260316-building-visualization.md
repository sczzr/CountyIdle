# 功能卡：建筑落地可视化（山门图建筑显影）

- 功能名：建筑落地可视化（山门图建筑显影）
- 任务 ID：`DL-087`
- 目标（玩家价值）：建造行为能在山门图上直观看见，增强扩建反馈感。
- 飞轮环节：产业涌现 → 反哺宗门
- 依赖：`TownMapGeneratorSystem`、`CountyTownMapViewSystem`、`IndustrySystem`

## 交付范围

- 山门图根据产业建筑数量生成对应锚点建筑显影，建造时优先落在选中地块；
- 建筑数量映射为可见锚点数量（有上限，避免堆满地块）；
- 建造后刷新地图可视化。

## 非目标

- 不新增建筑类型；
- 不改动建造成本、结算与存档结构；
- 不改变现有院域坊局与地块检视规则。

## 完成标准（DoD）

- [x] 建造任一产业建筑后，山门图出现对应建筑显影；
- [x] 建筑数量映射为可见锚点数量（有上限）；
- [x] 不改结算、建筑成本与存档结构；
- [x] `dotnet build .\Finally.sln` 通过。

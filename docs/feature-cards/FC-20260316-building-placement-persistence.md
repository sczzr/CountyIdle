# 功能卡：建筑落地持久化（山门图落点存档）

## 功能信息

- 功能名：建筑落地持久化（山门图落点存档）
- 优先级：P1
- 目标版本：Demo-V1
- 关联系统：`GameState`、`SaveSystem`、`CountyTownMapViewSystem`、`IndustrySystem`

## 目标与用户收益

- 目标：建造落点写入存档，读档后仍能保持原地块显影。
- 玩家可感知收益（10 分钟内）：建造后退出/读档仍能看到建筑落在原位置。

## 实现范围

- 包含：`GameState` 记录建筑落点，建造成功后写入落点，山门图刷新时复原锚点。
- 不包含：新增建筑类型、改动建筑成本/结算、持久化地图布局或地形种子。

## 实现拆解

1. `GameState` 增加建筑落点记录并纳入克隆与存档。
2. 建造成功后写入落点（重复地块替换）。
3. 山门图刷新时读取落点并复原锚点建筑。

## 验收标准（可测试）

- [ ] 建造后落点写入存档，读档后仍能复原建筑落点。
- [ ] 落点逻辑保持“优先选中地块，其次推荐落点”的规则不变。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：旧存档缺少落点字段导致复原为空。
- 回滚方式：移除落点字段与复原逻辑，回退到仅按数量显影。

# 功能卡：建筑列表与快捷建造

- 功能名：建筑列表与快捷建造
- 任务 ID：`DL-086`
- 目标（玩家价值）：集中展示可建造建筑的数量与成本，便于批量扩建。
- 飞轮环节：产业涌现 → 反哺宗门
- 依赖：`IndustrySystem`、`GameLoop.BuildIndustryBuilding`、右栏“天衍峰记事”面板

## 交付范围

- 右栏新增“营建清单”面板；
- 列出主要建筑（阵材圃、傀儡工坊、传法院、青云总坊、庶务殿）的数量与建造成本；
- 提供建造按钮，触发现有建造逻辑并记录日志。

## 非目标

- 不新增新建筑类型；
- 不改动建造成本、结算规则与存档结构；
- 不替换现有地块检视器与仓储面板入口。

## 完成标准（DoD）

- [x] 右栏出现“营建清单”面板；
- [x] 建筑数量与成本随 `GameState` 刷新；
- [x] 建造按钮触发现有建造逻辑并产生日志；
- [x] `dotnet build .\Finally.sln` 通过。

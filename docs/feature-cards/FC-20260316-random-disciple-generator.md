# 功能卡模板（Feature Card）

## 功能信息

- 功能名：随机弟子生成器（开发辅助）
- 优先级：`P2`
- 目标版本：当前迭代
- 关联系统：弟子谱 / `DiscipleRosterSystem` / `DiscipleProfile`

## 目标与用户收益

- 目标：提供可复现的随机弟子名册生成入口，用于弟子谱样式预览与系统调试，不改存档结构与主结算链。
- 玩家可感知收益（10 分钟内）：玩家侧无直接收益；开发侧可快速生成可读名册，便于 UI/规则预览。

## 实现范围

- 包含：随机生成 `DiscipleProfile` 列表；支持可选随机种子；不写入 `GameState`。
- 不包含：存档结构变更、正式弟子实体化、弟子谱新增按钮或入口。

## 实现拆解

1. 在 `DiscipleRosterSystem` 增加随机名册生成方法，复用现有弟子字段口径。
2. 更新 `docs/02_system_specs.md` 的弟子调度说明（开发辅助口径）。
3. 回写开发列表与功能台账。

## 验收标准（可测试）

- [ ] `DiscipleRosterSystem.BuildRandomRoster(GameState, int, int?)` 可返回指定数量的 `DiscipleProfile`。
- [ ] 传入相同种子时结果可复现；不传种子时具备随机性。
- [ ] 生成结果不写入 `GameState`，不改存档与小时结算链。

## 风险与回滚

- 风险：误把开发辅助结果当作正式存档入口使用。
- 回滚方式：移除随机生成方法并回滚文档记录。

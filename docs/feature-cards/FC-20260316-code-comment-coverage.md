# 功能卡：代码中文注释规范化（存量补注）

## 功能信息

- 功能名：代码中文注释规范化（存量补注）
- 优先级：`P2`
- 目标版本：当前迭代
- 关联系统：工程质量 / 可维护性

## 目标与用户收益

- 目标：为全仓库代码补齐中文注释，明确关键逻辑、边界与接口意图，降低协作理解成本。
- 玩家可感知收益（10 分钟内）：无直接可见变化，但降低后续迭代风险与误改概率。

## 实现范围

- 包含：`CountyIdle/scripts`（`core/models/systems/ui`）与相关 `GDScript`、必要的工具脚本注释补齐。
- 不包含：行为逻辑改动、玩法规则调整、存档格式变更。

## 实现拆解

1. 建立统一规则：在 `AGENTS.md` 与开发列表中明确注释要求。
2. 按目录分批补注：`core` → `models` → `systems` → `ui` → `*.gd`。
3. 最终统一校验并记录验证结果。

## 验收标准（可测试）

- [ ] 代码文件包含中文注释（类/方法/关键逻辑与边界说明）。
- [ ] 不改变运行行为与数据结构。
- [ ] `dotnet build .\\Finally.sln` 通过。

## 风险与回滚

- 风险：注释误导或过度冗长，影响可读性。
- 回滚方式：仅回退注释提交，不触碰逻辑代码。

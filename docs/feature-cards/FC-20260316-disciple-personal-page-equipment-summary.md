# 弟子个人页装备/法器摘要（Feature Card）

## 功能信息

- 功能名：弟子个人页装备/法器摘要
- 优先级：P2
- 目标版本：当前迭代
- 关联系统：弟子谱 / 装备掉落 / 存档

## 目标与用户收益

- 目标：在弟子个人页补入装备/法器摘要，并以轻量字段持久化每位弟子的行装概况。
- 玩家可感知收益（10 分钟内）：打开弟子谱即可看到“装备/法器”一行，快速判断战备配置与品质档位。

## 实现范围

- 包含：
  - 新增弟子装备档案模型与存档字段（GameState）。
  - 由弟子名册构建时生成默认装备摘要，缺失时自动补全。
  - 弟子个人页卷中详录展示装备/法器摘要。
- 不包含：
  - 装备打造链路、掉落分配与真实装备栏。
  - 装备数值对战力/结算的系统联动。

## 实现拆解

1. 新增弟子装备档案模型，并挂接到 GameState（含 Clone 处理）。
2. 在弟子名册构建中生成/补全装备档案，保证旧存档可读。
3. 弟子个人页新增装备/法器摘要行并统一文案。

## 验收标准（可测试）

- [ ] 弟子谱个人页可展示“装备/法器”摘要行。
- [ ] 旧存档读取不报错，缺省装备档案可自动补齐。
- [ ] `dotnet build .\\Finally.sln` 通过。

## 风险与回滚

- 风险：新增存档字段导致旧档案字段缺省或显示空白。
- 回滚方式：移除装备档案字段与 UI 摘要行，恢复为无装备显示版本。

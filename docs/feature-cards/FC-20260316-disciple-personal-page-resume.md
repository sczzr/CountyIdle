# 功能卡：弟子个人页履历与修行摘要

## 功能信息

- 功能名：弟子个人页履历与修行摘要
- 优先级：`P2`
- 目标版本：`2026-03-16 UI 强化`
- 关联系统：`DL-043`、`DisciplePanel`、`DiscipleRosterSystem`、`docs/16_cultivator_classification_design.md`

## 目标与用户收益

- 目标：在弟子个人页的卷中详录内补入“履历侧记 + 修行阶段”两行，帮助玩家快速抓住弟子当前轨迹与修行档位。
- 玩家可感知收益（10 分钟内）：在不翻查其他面板的情况下即可读到“现在主要做什么/身在何处/修行处于哪一段”。

## 实现范围

- 包含：
  - 卷中详录在“身份与籍录”段新增履历侧记。
  - 卷中详录在“修为与功法”段新增修行阶段（初/中/高 + 具体境界）。
- 不包含：
  - 不新增弟子履历、装备或关系系统字段。
  - 不改动修为数值公式与结算节奏。

## 实现拆解

1. 在 `DisciplePanel.cs` 追加履历侧记与修行阶段派生 helper。
2. 将两条新文案插入详录对应分组。
3. 回写功能卡与台账记录。

## 验收标准（可测试）

- [x] 详录出现履历侧记与修行阶段两行。
- [ ] 不影响筛选、排序与详情切换。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：详录行数继续增加，滚动阅读压力上升。
- 回滚方式：移除新增行与 helper，恢复上一版详录。

# 功能卡模板（Feature Card）

## 功能信息

- 功能名：弟子谱随机名册预览按钮（调试）
- 优先级：`P2`
- 目标版本：当前迭代
- 关联系统：弟子谱 / `DiscipleRosterSystem`

## 目标与用户收益

- 目标：在弟子谱内提供“随机名册预览”调试入口，便于 UI 与字段口径验证。
- 玩家可感知收益（10 分钟内）：玩家侧无直接收益（调试入口，默认仅在 Debug 构建可见）。

## 实现范围

- 包含：弟子谱内按钮；随机名册预览与恢复宗门名册切换；批注禁用保护。
- 不包含：存档结构变更、正式弟子实体化、主结算链改动。

## 实现拆解

1. 在弟子谱 UI 增加调试按钮节点并接入脚本逻辑。
2. 预览模式下调用 `DiscipleRosterSystem.BuildRandomRoster`，不写入 `GameState`。
3. 调试入口仅 Debug 构建可见，避免影响正常玩家流程。

## 验收标准（可测试）

- [ ] Debug 构建下显示“随机名册预览”按钮；非 Debug 构建隐藏。
- [ ] 点击后生成随机名册并刷新弟子谱；再次点击恢复宗门名册。
- [ ] 预览模式下弟子批注不可用且有提示。

## 风险与回滚

- 风险：误把调试入口带到正式版本或误写入存档。
- 回滚方式：移除弟子谱调试按钮与预览逻辑，保留随机名册生成器。

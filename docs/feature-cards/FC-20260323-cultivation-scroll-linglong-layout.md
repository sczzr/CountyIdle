# FC-20260323：修炼卷宣纸化重构（敕令修行 · 玲珑调度）

## 功能信息

- 功能名：修炼卷宣纸化重构（敕令修行 · 玲珑调度）
- 优先级：P1
- 目标版本：2026.03（当前迭代）
- 关联系统：`CultivationPanel`、`CultivationPanelVisualFx.gd`、修炼卷可复用组件、卷册 UI 总纲

## 目标与用户收益

- 目标：依据《山海机局》UI 设计总纲，将修炼卷从沉重的黑金后台风格收口为“宣纸 + 玉璧 + 朱砂敕令”的卷册氛围，并保留现有弟子切换、修炼敕令与持久化结算逻辑不变。
- 玩家可感知收益（10 分钟内）：打开修炼卷时，能直接看到更轻的宣纸底色、左侧“弟子灵鉴”玉璧、右上“玲珑心位”与中部更像符纸的法门卡片；点击法门后，朱砂印记与心位点亮反馈更明确。

## 实现范围

- 包含：
  - 将 `CultivationPanel` 主视觉从深色玻璃卡改为宣纸底、淡金墨线、玉色进度与朱砂激活态。
  - 将右上角状态徽记重构为“玲珑心位”语义，并按弟子资质显示 1~3 枚槽位。
  - 将法门卡的时长改为竖排“壹时辰”小楷表达，激活态统一为“敕令”印章语义。
  - 补入 `exquisite_heart.svg` 与 `decree_talisman.svg`，并把两者真正挂到 `CultivationPanel.tscn` 的心位节点与法门卡节点上。
  - 在 `CultivationPanelVisualFx.gd` 中补一段 Godot 原生 tween 的“朱砂盖印”轻动效。
  - 在四张法门卡中补 `SealSplash` 中央印痕层，让敕令落下时出现短暂扩散的朱砂印泥效果，并让符纸纹理同步提亮为金纹显影。
- 不包含：
  - 改动 `GameState` 结构或把单主修规则改为多法门同时激活。
  - 新增复杂粒子、Lottie、专门的 Godot 插件依赖。
  - 修炼结算数值与专精规则重平衡。

## 实现拆解

1. 先登记新一轮修炼卷视觉收口需求，并把它挂回既有 `DL-088 / DL-095` 能力线上，而不是另起孤立页面。
2. 调整 `CultivationPanel.tscn` 静态文案与版式基线，让“弟子灵鉴 / 玲珑心位 / 敕令修行”这些关键语义在场景层直接可见。
3. 在 `CultivationPanelVisualFx.gd` 中把背景、卡片、标签、敕令状态与时长徽记统一改为宣纸/玉色/朱砂体系。
4. 在 `CultivationPanel.cs` 中补齐玲珑心位刷新逻辑，并继续保证现有单主修权威逻辑不变。
5. 文档回写 `05 / 08 / FC`，记录这是修炼卷 UI 精修而非新系统。

## 风险与回滚

- 风险：
  - 修炼卷节点较多，若场景层文案/容器或 VisualFx 路径偏移，容易引发运行时取节点失败或样式缺失。
  - “玲珑心位”当前仅是单主修规则上的视觉映射，如果文案表达过度，可能让玩家误以为支持多法门并行。
- 回滚方式：优先回退视觉资源与样式函数，保留 `CultivationPanel.cs` 的数据刷新与单主修逻辑；若仍需进一步收缩，可只保留宣纸配色与“敕令”文案，不启用心位显示。

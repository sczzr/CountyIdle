# 功能卡：灵鉴录·清简留白（弟子谱极简玉简重构）

## 功能信息

- 功能名：灵鉴录·清简留白（弟子谱极简玉简重构）
- 对应任务：`DL-092`、`DL-094`
- 优先级：`P1`
- 目标版本：`2026-03-23`
- 关联系统：`DisciplePanel`、`DiscipleRosterSystem`、`SectNamingRules`

## 目标与用户收益

- 目标：全面推翻此前厚重、密集的弟子谱树页，把“宗门大谱”重构为更轻、更空、更像主界面设置页的现代中式展签式谱录。
- 玩家可感知收益（10 分钟内）：
  - 打开弟子谱时，先看到左侧“支脉导航”与右侧“血脉族谱”，而不是拥挤的多层卡堆。
  - 各支脉改用垂直胶囊玉简切换，当前支脉以朱砂红高亮。
  - 右侧谱系节点改为胶囊玉简 + 极细连枝线 + 展签侧记，选中弟子后再进入命谱详情。

## 设计裁定

### 1. 视觉语言

- 左侧导航改为“胶囊玉简”支脉切片，默认白绿玉色，选中为朱砂红。
- 右侧谱系树使用更大的留白、极细连接线与淡水印字，不再堆叠厚重块状卡片。
- 节点名称采用近似竖排的逐字断行，旁侧信息改为美术馆展签式横向细字。

### 2. 交互逻辑

- 左侧只负责切支脉，不直接打开详情。
- 右侧点击弟子玉简进入命谱详情页，返回后仍保留当前支脉与选中目标。
- 悬停只做轻微上浮和展签显隐，不做夸张翻转。

### 3. 实现边界

- 保持 `DisciplePanel` 现有数据绑定、筛选、排序、命谱详情、修炼卷跳转与敕令批注逻辑不变。
- 本轮主要重构树页结构与表现，不改 `GameState`、弟子生成、修炼结算或卷册排他规则。
- 继续复用现有命谱详情页，避免把本轮工作扩散成新的系统级重构。

## 实现拆解

1. 在 `DisciplePanel` 内以代码重组树页布局，形成左导航 / 右谱系的新骨架。
2. 将现有标题、筛选、摘要、调试入口回收进左侧导航列，避免重复维护数据节点。
3. 在右侧动态生成“主脉节点 + 门人玉简节点 + 极细连枝线”。
4. 保留原命谱详情页与现有 `VisualFx` 职责边界，仅让树页改走新的极简布局。

## 验收标准（可测试）

- [x] 支脉切换使用胶囊玉简表达，当前支脉为朱砂红高亮。
- [x] 右侧谱系节点使用竖向玉简与极细连线，并可点击弟子进入命谱详情。
- [x] 返回命谱详情后，当前支脉与当前弟子高亮保持连续。
- [x] `dotnet build .\Finally.sln` 通过。

## 风险与后续验证

- 风险：
  - 本轮树页布局大量依赖运行时创建控件，`dotnet build` 无法替代 Godot 场景级视觉走查。
  - 竖排感目前通过逐字断行模拟，仍需在实机分辨率下检查字体、间距与裁切感。
- 后续：
  - 需要补 `F5` / Godot 实机走查，确认 hover 浮动、树线位置、滚动高度与 720p / 宽屏下留白是否符合预期。

# 功能卡：地图平地留白与黄金比例地形显影

## 功能信息

- 功能名：地图平地留白与黄金比例地形显影
- 优先级：P1
- 目标版本：2026.03
- 关联系统：`StrategicMapViewSystem`、`CountyTownMapViewSystem`、`WorldTerrainVisualRules`、世界图 / 山门图 / 二级地图运行时渲染链

## 目标与用户收益

- 目标：调整地图地块显示逻辑，让世界图、山门图与二级地图默认以留白平地承接底图，只在确实需要强调地貌差异时才绘制地形贴图，并把整体留白节奏收口到“空白地块 : 地形地块 ≈ 黄金比例”。
- 玩家可感知收益（10 分钟内）：地图不再被满屏纹理塞满，平地更清爽，水域/雪地/荒岭/灵地等重点地貌一眼可读，地图呼吸感更强。

## 实现范围

- 包含：
  - 为世界图增加“显式地形贴图候选”筛选逻辑，默认平地不贴图。
  - 为山门图 / 二级地图增加同口径的“显式地形贴图候选”筛选逻辑，默认普通地面不贴图。
  - 仅对水域、雪地、荒岭、灵地，以及带奇观/结构/灵脉/资源等高辨识度地块优先绘制 L1 贴图。
  - 用稳定的优先级排序控制显式贴图数量，使留白 hex 与显式地形 hex 尽量接近 `1.618 : 1`。
  - 保持道路 / 河流 / 悬崖 / 站点 / 标签 / 选中高亮的现有叠加层逻辑不变。
- 不包含：
  - 不改世界图生成算法本身。
  - 不新增新的地形素材或 overlay 资产。

## 实现拆解

1. 在世界图渲染链里把“默认平地留白”设为正式规则。
2. 将同样规则同步到山门图 / 二级地图的基础地块绘制。
3. 为各类 hex 建立“显式贴图优先级”评分，优先保留真正需要强调的地貌。
4. 以黄金比例为目标控制显式贴图数量，并保持结果稳定可复现。
5. 回写 `05 / 08 / 02` 文档口径。

## 验收标准（可测试）

- [ ] 世界图不再为每个地块都绘制 L1 贴图。
- [ ] 山门图 / 二级地图的普通地面也不再为每格都强制贴图。
- [ ] 默认平地会直接透出底图，不再额外贴地形纹理。
- [ ] 水域 / 雪地 / 荒岭 / 灵地及高辨识度特殊格优先保留贴图。
- [ ] 地图留白 hex 与显式地形贴图 hex 的目标比例收口到约 `1.618 : 1`。
- [ ] `dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：
  - 若显式贴图筛选过猛，可能削弱局部地貌辨识度。
  - 若优先级权重不合理，奇观附近可能被普通地貌挤掉。
- 回滚方式：
  - 恢复世界图“所有 hex 都绘制 L1 贴图”的旧逻辑；
  - 保留本次文档记录，后续再单独调整筛选权重。

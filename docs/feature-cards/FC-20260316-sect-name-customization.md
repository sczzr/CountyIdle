# 功能卡（Feature Card）

## 功能信息

- 功能名：宗门命名自定义（宗门/峰/堂口全替换显示名）
- 对应任务：`DL-102`
- 优先级：`P1`
- 目标版本：`V3.x`
- 关联系统：`GameState` / 存档系统 / 宗主中枢 / 山门图 / 事件与日志 / 宗门语义规则

## 目标与用户收益

- 目标：允许玩家自定义宗门、峰与堂口的显示名，玩家可见文本全部替换为自定义名，同时保持内部稳定 ID 不受影响。
- 玩家可感知收益（10 分钟内）：在宗门档案改名后，山门图与日志立即出现玩家命名的宗门与堂口称谓。

## 实现范围

- 包含：
  - `GameState` 新增宗门命名配置（默认名 + 自定义名）。
  - 宗主中枢/宗门档案入口，支持编辑宗门/峰/堂口显示名与“恢复默认”。
  - 玩家可见文本统一读取显示名，缺失时回落默认名。
  - 读档兼容：旧存档无命名数据时自动补默认名。
- 不包含：
  - 核心结算、资源与事件逻辑改动。
  - 新增峰/堂口数量与组织结构重构。
  - 多语言/敏感词过滤系统。

## 实现拆解

1. `GameState` 增加命名配置结构与默认回落规则，并接入存档读写。
2. 宗主中枢/宗门档案 UI 接入编辑表单与校验规则（去首尾空格、禁止换行、长度限制）。
3. 山门图/卷宗/日志/事件/调度提示文本统一改用显示名读取器。

## 验收标准（可测试）

- [ ] 宗主中枢/宗门档案可编辑宗门名、主峰名、核心堂口名，并支持一键恢复默认。
- [ ] 山门图标签、卷宗标题、日志事件、调度提示统一使用玩家显示名。
- [ ] 旧存档缺失命名数据时能自动回落默认名，不影响读档与结算。
- [ ] 命名输入限制生效（去首尾空格、禁换行、长度上限）。
- [ ] `dotnet build .\\Finally.sln` 通过。

## 风险与回滚

- 风险：UI 溢出与文本混用；部分旧文案漏替换导致语义不一致。
- 回滚方式：停用显示名替换，统一回退默认名；保留存档字段但忽略读取。

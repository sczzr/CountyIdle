# FC-20260316：弟子修炼卷（修炼安排页）

## 功能信息

- 功能名：弟子修炼卷（修炼安排页）
- 优先级：P1
- 目标版本：2026.03（当前迭代）
- 关联系统：弟子谱、传承研修、技艺体系、主界面卷册弹窗

## 目标与用户收益

- 目标：提供一个统一的修炼安排页面，集中管理技能修炼、功法打磨、技艺练习与打坐修炼。
- 玩家可感知收益（10 分钟内）：能快速找到修炼入口并完成安排/撤销操作，获得清晰状态提示。

## 实现范围

- 包含：主界面新增“修炼”入口；修炼卷弹窗；四类修炼卡片与状态提示；按钮反馈与占位文案。
- 不包含：修炼效果接入时辰结算、功法/技艺真实成长数值、存档结构调整。

## 实现拆解

1. 新增修炼卷 `CultivationPanel` 场景与 UI 布局。
2. 增加 `CultivationPanel.cs` 处理打开/关闭、状态提示与占位逻辑。
3. 主界面接入按钮与弹窗生命周期（含弹窗排他）。
4. 文档回写（`05/08` + 本功能卡）。

## 验收标准（可测试）

- [ ] 底栏新增“修炼”按钮，点击可打开修炼卷，Esc/关闭按钮可关闭。
- [ ] 卷内包含技能修炼 / 功法打磨 / 技艺练习 / 打坐修炼四类卡片与状态文案。
- [ ] 点击按钮可切换安排状态并显示提示（含“待接入结算”说明）。
- [ ] 不改小时结算与存档结构，`dotnet build .\Finally.sln` 通过。

## 风险与回滚

- 风险：仅 UI 占位，玩家可能期待实际收益。
- 回滚方式：移除入口按钮与修炼卷场景，保持现有卷册链路。

# FC-20260316：弟子修炼卷（修炼安排页）

## 功能信息

- 功能名：弟子修炼卷（修炼安排页）
- 优先级：P1
- 目标版本：2026.03（当前迭代）
- 关联系统：弟子谱、传承研修、技艺体系、主界面卷册弹窗

## 目标与用户收益

- 目标：提供一个统一的修炼安排页面，集中管理技能修炼、功法打磨、技艺练习与打坐修炼，并支持从弟子谱直接联动到当前弟子；卷面以“左侧弟子点名册 + 当前阵眼 HUD，右侧玉简法门矩阵”的空间化布局强化修仙题材直觉，并继续把长期火候细化成更明确的专修分支与功法技艺专精。
- 玩家可感知收益（10 分钟内）：能快速找到修炼入口，为指定弟子完成安排/撤销操作，并在弟子谱、修炼卷与时辰结算日志中看到一致反馈；持续安排后还能看到个体长期火候积累、近时修炼履历、培养路数摘要、专修分支、功法技艺专精，以及这些火候对个体表现、重点差事适配、修炼感悟札记、轻量机缘与专精效用的温和反哺。

## 实现范围

- 包含：主界面新增“修炼”入口；修炼卷弹窗；将卷面重构为“左侧弟子点名册 + 当前阵眼 HUD，右侧 2x2 玉简法门矩阵”的全屏沉浸式布局，并继续把点名册卡牌化为字章 / 境界 / 主修 / 分支短签联读；修炼卷视觉进一步图形化（标签化身份信息、菱形刻度火候、属性块收益、状态槽式当前运转周天，移除长段说明文字）；卷首返回/关闭、总览摘要、点名册、阵眼切换与左右法门区块优先在 `CultivationPanel.tscn` 里摆好可见基线，再由 `C# / GDScript` 只做状态刷新、样式与动效微调；四类修炼卡片与状态提示；按弟子保存主修安排；弟子谱跳转修炼卷；四类修炼安排接入时辰结算聚合收益；逐弟子的长期成长摘要与弟子谱展示；近时修炼履历回看；长期火候对个体表现的温和联动；基于主导火候生成培养路数摘要与路数批语；再结合次强火候分出专修分支与分支批注；将分支进一步映照到功法 / 主修技艺 / 辅修技艺专精称谓，并在分支成形时补记专名履历；继续让专修分支落成更明确的专精效用；将培养路数继续接入外务候补 / 执事培养 / 内务补位的轻量差事优势，并用专修分支做更细一层修正；在任务详情 / 探险日志 / 批注结果中回显相性说明与专精效用；并周期生成面向玩家可见的修炼感悟札记，在札记触发时结出轻量机缘并回显最近感悟。
- 不包含：独立复杂修炼履历面板、复杂分支树、直接改写弟子基础属性的永久成长。

## 实现拆解

1. 新增修炼卷 `CultivationPanel` 场景与 UI 布局，加入当前弟子上下文与四类修炼卡片。
2. 增加弟子修炼安排规则与系统，按 `弟子ID -> 主修类型` 写入 `GameState`。
3. 主界面接入按钮、弹窗生命周期与 `GameLoop` 变更入口（含弹窗排他）。
4. 弟子谱增加“送入修炼卷”跳转入口，并显示当前修炼卷状态。
5. 新增修炼小时结算折算层，并把收益日志接入主结算链路。
6. 为四类修炼安排新增长期成长持久化，并在弟子谱/修炼卷展示火候摘要。
7. 为弟子追加近时修炼履历，并在修炼卷/弟子谱展示最近若干条记录。
8. 让长期火候温和反哺弟子个体表现，并把反馈展示回弟子谱/修炼卷。
9. 根据长期火候归纳培养路数摘要/路数批语，并展示回弟子谱/修炼卷。
10. 将培养路数接入外务候补 / 执事补位评分与执行修正，并把差事相性回显到弟子谱/修炼卷/指令文案。
11. 当火候成形后，周期生成修炼感悟札记，并在札记触发时结出轻量机缘，同步回写到主界面近闻、见闻报表卷与弟子个人履历。
12. 将卷面从纵向表单重构为“弟子点名册 + 当前阵眼 HUD + 玉简矩阵”的全屏沉浸式空间布局，突出点名切换、四条火候进度、当前安排与最近感悟。
13. 根据主导火候 + 次强火候推导专修分支，并把分支摘要 / 分支批注 / 更细差事偏向接回弟子谱、修炼卷与任务叙述。
14. 将专修分支进一步映照到功法/主修技艺/辅修技艺专精称谓，并在分支成形或转向时补记专名履历。
15. 将专修分支继续落成轻量专精效用，并把效用回显到弟子谱、修炼卷与相关结果说明。
16. 将专精效用进一步回显到任务详情、外务战报与批注结果说明。
17. 文档回写（`02/05/08` + `CP/BL` + 本功能卡）。

## 风险与回滚

- 风险：当前收益采用“聚合折算 + 长期成长 + 履历回看 + 个体表现联动 + 路数批语 + 分支批语 + 专精称谓 + 专精效用 + 差事优势联动 + 感悟札记/机缘”，若联动文本过密，可能影响卷册与日志可读性。
- 回滚方式：先移除专精效用展示与相关结果回显；如仍需继续收缩，再回退功法/技艺专精映照与专名履历；修炼卷入口、修炼安排字典字段、时辰结算聚合收益、长期成长摘要、履历回看、个体表现联动与基础路数优势链路可保持不变。

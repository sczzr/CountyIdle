# Handoffs 索引

本目录存放多 Agent / 多阶段交接记录。  
命名规则：`HO-YYYYMMDD-canonical-topic.md`

## 用途

- 记录某一轮工作已经做完什么、还剩什么、谁接着做。
- 在任务跨度较长、需要切换负责人、或本轮只完成“验证 / 收口 / 排障”时，作为最轻量的持续上下文。
- 和功能卡、提案、平衡日志不同，交接记录更关注“当前基线、风险、下一步动作”。

## 最低记录标准

每份交接至少包含：

1. 任务ID与当前状态
2. 已改文件 / 待改文件
3. 已完成内容与已通过验证
4. 风险与建议
5. 下一位责任 Agent

# BL-20260318：弟子修炼卷差事优势联动

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-duty-affinity.md`

## 改动摘要

- 改动项：让培养路数继续影响外务候补、执事补位与具体内务执行修正，并把差事相性展示给玩家。
- 改动前：玩家能看见“这个弟子被练成了什么样”，但还不容易看出“所以该把他放到哪条职责线上”。
- 改动后：
  - `功法火候` 更偏外务历练 / 护山巡检 / 研修差事
  - `技艺手感` 更偏工坊营造 / 总坊整备 / 执事补位
  - `静修积气` 更偏长线值守 / 讲法校勘
  - `根基磨砺` 更偏田务轮值 / 巡检补位 / 稳态内务

## 结果数据

- 指标 1：培养路数现在会继续影响 `外务候补` 前列排序、`执事培养` 候补评分与具体内务执行修正，专精路线不再只是文本标签。
- 指标 2：弟子谱、修炼卷、任务详情与指令反馈现在都能显示“差事相性”，玩家更容易理解这名弟子的投放方向。
- 指标 3：当前联动仍为轻量修正，不新增新的持久化字段，也不替代原有岗位基础值。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：把差事优势折算继续挂在 `DiscipleCultivationRules` + `DiscipleDirectiveRules` 组合上，能同时影响真实治理链路与卷册文案，避免出现“只会写字不会生效”的割裂。
- 无效原因：当前仍是轻量职责相性，还没有接入更复杂的专属事件、职业树或外务战斗技能。
- 后续假设：下一轮可继续围绕“更细技能/功法成长联动”深化，让不同路线进一步延伸到专属事件、岗位专长或产出差异。

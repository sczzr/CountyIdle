# BL-20260318：弟子修炼卷小时结算

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-hour-settlement.md`

## 改动摘要

- 改动项：将修炼卷四类安排接入时辰结算，并把收益日志挂到 `GameLoop` 主链。
- 改动前：修炼卷只能登记“技能修炼 / 功法打磨 / 技艺练习 / 打坐修炼”，不会对时辰结算产生任何收益。
- 改动后：
  - `技能修炼`：少量 `Research + ContributionPoints`
  - `功法打磨`：更高 `Research`
  - `技艺练习`：少量 `IndustryTools + ContributionPoints`
  - `打坐修炼`：少量 `Happiness` 与 `Threat` 缓冲

## 结果数据

- 指标 1：可见反馈从“0 条修炼收益日志/时辰”提升到“有安排时每时辰 1 条修炼卷收益日志”。
- 指标 2：以中位弟子假设（悟性 / 匠艺 / 执行 / 心境 / 体魄约 `55`，修为 `T1`）估算，单名弟子每时辰理论收益约为：技能修炼 `研修 +0.119 / 贡献 +0.032`，功法打磨 `研修 +0.158`，技艺练习 `工器 +0.173 / 贡献 +0.027`，打坐修炼 `民心 +0.113 / 危兆 -0.032`。
- 指标 3：单名弟子在“功法打磨”下的理论研修收益约为 `0.158/时辰`，显著低于现有学士主链的 `0.46/时辰`，当前仍属于辅助回流而非主收益替代。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：修炼卷结算被插入到 `Economy -> Cultivation -> Research` 顺序中，既能保持收益可见，又不会打散现有系统边界。
- 无效原因：当前只做聚合折算，仍缺逐弟子的长期功法/技艺成长与更细的收益回看。
- 后续假设：下一轮可在不改变当前聚合收益的前提下，为弟子追加长期熟练度/法门稳固度字段，并把阶段性成长展示回卷册与弟子谱。

## 改动摘要

- 改动项：把专修分支进一步映照到功法 / 主修技艺 / 辅修技艺称谓，并在分支成形时补记专名履历。
- 改动前：玩家能通过说明文本知道弟子偏向哪条分支，但功法与技艺栏位仍偏泛称。
- 改动后：
  - 弟子的功法会根据专修分支继续显出偏锋
  - 主修技艺 / 辅修技艺会更贴近当前培养偏向
  - 分支成形节点会被记入个人修炼履历，强化养成阶段感

## 结果数据

- 指标 1：弟子最核心的功法 / 技艺标签已能直接承接专修分支，而不是只留在说明段里。
- 指标 2：分支成长从“静态判定”升级为“带节点感的履历事件”，玩家更容易感知长期培养在发生变化。
- 指标 3：仍沿用现有火候与分支推导，不新增新的存档字段。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

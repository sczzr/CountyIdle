# BL-20260318：弟子修炼卷个体表现联动

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-performance-feedback.md`

## 改动摘要

- 改动项：让长期火候温和反哺弟子个体表现，并把结果展示到弟子谱与修炼卷。
- 改动前：修炼火候与履历虽然可见，但弟子本身的表现变化还不够明显。
- 改动后：
  - `根基磨砺` 温和提升执行 / 气血 / 战修
  - `功法火候` 温和提升悟性 / 战修
  - `技艺手感` 温和提升匠艺 / 执行 / 贡献
  - `静修积气` 温和提升心境 / 气血

## 结果数据

- 指标 1：在火候封顶附近，单项联动加成仍被控制在个位数范围内，当前属于“可感知但不翻盘”的档位。
- 指标 2：修炼火候会同时改写弟子谱中的派生表现与修炼卷中的状态摘要，玩家不再只看见“有积累”，还能看见“这个人更稳了 / 更能战了 / 更会做事了”。
- 指标 3：联动加成来自长期火候，不新增永久底表字段，因此旧存档兼容与回滚成本都较低。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：火候联动挂在 `DiscipleRosterSystem` 的派生链上，能同时影响卷册显示和相关系统读取，避免出现“UI 变了但系统没变”的割裂。
- 无效原因：当前仍是温和联动，还没有进入更复杂的专精流派或分支成长。
- 后续假设：下一轮可围绕“更细技能/功法成长联动”继续深化，让不同修炼路线出现更鲜明的弟子个体风格。

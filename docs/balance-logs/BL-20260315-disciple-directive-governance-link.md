## 改动摘要

- 改动项：弟子谱交互指令接入（二期：治宗落实联动）
- 改动前：`执事培养` 只影响贡献回流，治宗册中的“执事落实”文本与内务条目效率没有直接联动。
- 改动后：`执事培养` 同时影响内务执行效率，并在治宗册摘要、职司摘要与条目详情中显式反馈。

## 结果数据

- 指标 1：若未点定执事培养对象，则治宗册执行摘要与内务效率保持原样，不改旧节奏。
- 指标 2：按当前规则样例，若点定 `4` 名执事培养且其平均 `执行≈72 / 悟性≈66 / 贡献≈58`，则内务执行效率约 `+7%`，并继续叠加一期的贡献回流修正。
- 指标 3：外务专属条目 `外事行商` 不吃该二期效率修正，保持“执事培养主内务、外务候补主外务”的职责边界。

## 结论

- 是否达到预期：是（已形成“弟子谱批注 -> 治宗册执行反馈 -> 内务收益变化”的第二条闭环）。
- 下一步：继续扩到正式执事任命、任务候选权重和长期履历。

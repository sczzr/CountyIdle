# BL-20260318：弟子修炼卷专修分支成长联动

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-specialization-branches.md`

## 改动摘要

- 改动项：在既有培养路数之上，继续用“主导火候 + 次强火候”推导专修分支，并把分支摘要/批注与更细差事偏向挂回弟子谱、修炼卷和相关任务叙述。
- 改动前：玩家能看懂弟子大致走的是哪条路数，但同一路数内部的差异还不够鲜明。
- 改动后：
  - `根基磨砺` 可继续分出 `田务固本 / 巡山劲行 / 营造固本 / 守心稳阵`
  - `功法火候` 可继续分出 `法门专修 / 外务锋行 / 器理推演 / 讲法悟玄`
  - `技艺手感` 可继续分出 `总坊整备 / 营造砺身 / 炼器演法 / 丹火守息`
  - `静修积气` 可继续分出 `澄心守气 / 守山静值 / 讲法澄悟 / 养息调工`

## 结果数据

- 指标 1：弟子谱 / 修炼卷中已能直接读到“培养路数 + 专修分支”两层信息。
- 指标 2：差事相性叙述会继续带出当前专修分支，使“为什么这个人更适合这条差事”更容易解释。
- 指标 3：分支仍完全由现有长期火候推导，不新增新的存档字段，保持兼容成本低。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：把“主导火候 + 次强火候”作为分支依据，能在不加新字段的前提下自然拉开同一路数内部的差异。
- 无效原因：当前仍属于轻量成长分支，还没有形成完整的可选分支树、独立事件链或永久成长页。
- 后续假设：下一轮可继续围绕“更细技能/功法成长联动”推进，把部分专修分支进一步接到明确的技能/功法专精效果上。

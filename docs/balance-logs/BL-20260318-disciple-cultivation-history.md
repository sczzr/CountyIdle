# BL-20260318：弟子修炼卷履历回看

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-history.md`

## 改动摘要

- 改动项：为修炼卷新增逐弟子近时履历，并把最近记录展示到弟子谱与修炼卷。
- 改动前：玩家只能看到当前主修与长期火候，无法回看最近的主修切换和关键成长节点。
- 改动后：
  - 主修切换时追加履历
  - 火候跨阶段时追加履历
  - 卷册内可回看最近若干条记录

## 结果数据

- 指标 1：每名弟子的履历列表默认仅保留最近 `6` 条记录，避免无限增长。
- 指标 2：当前设计下，普通时辰不会额外写履历，只有“主修切换 / 关键火候跃迁”才入卷，日志噪声显著低于逐时辰记录方案。
- 指标 3：弟子谱详情与修炼卷都读取同一份履历列表，避免“卷内有记录 / 谱内无记录”的口径分裂。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：履历收口在修炼规则层统一维护，既复用了现有持久化链，也减少了 UI 自己拼接状态的风险。
- 无效原因：当前仍是“最近若干条”列表，还不是完整可筛读的修炼时间轴。
- 后续假设：下一轮若继续深化，可把履历扩展为独立卷内子区块，并增加按修炼类型筛读。

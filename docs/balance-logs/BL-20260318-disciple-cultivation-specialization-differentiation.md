# BL-20260318：弟子修炼卷专精差异化联动

## 记录信息

- 日期：2026-03-18
- 版本：2026.03
- 关联提案：`docs/change-proposals/CP-20260318-disciple-cultivation-specialization-differentiation.md`

## 改动摘要

- 改动项：根据长期火候主导方向，为弟子谱与修炼卷补上培养路数摘要与路数批语。
- 改动前：玩家能看见火候与反哺，但还不容易一眼判断某名弟子究竟更偏功法、技艺、静修还是根基。
- 改动后：
  - `功法火候` 主导时强调 `悟性 / 战修偏盛`
  - `技艺手感` 主导时强调 `匠艺 / 执行见长`
  - `静修积气` 主导时强调 `心境 / 气血更稳`
  - `根基磨砺` 主导时强调 `执行 / 气血更稳`

## 结果数据

- 指标 1：不新增新的持久化字段，只基于既有长期火候归纳路线，因此旧存档兼容风险较低。
- 指标 2：修炼卷与弟子谱现在都能同步显示“培养路数 / 路数批语”，不同弟子的长期培养差异更容易被玩家读出来。
- 指标 3：当前差异化仍以文本归纳和表现辨识为主，不会额外改写现有时辰收益或永久底表。

## 结论

- 是否达到预期：`是`
- 下一步：`保留`

## 复盘

- 有效原因：把路线归纳放在 `DiscipleCultivationRules` 中集中生成，可让弟子谱与修炼卷始终读取同一口径，避免“卷里一套、谱里一套”。
- 无效原因：当前还只是轻量专精表达，没有进入更复杂的技能树、专属事件或永久成长分支。
- 后续假设：下一轮可继续围绕“更细技能/功法成长联动”深化，让专精路线进一步接到具体事件、差事优势或专属产出。

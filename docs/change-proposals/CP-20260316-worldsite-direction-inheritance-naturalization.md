# 改动提案（Change Proposal）

## 提案信息

- 标题：世界格 -> 二级地图方向继承自然化
- 日期：2026-03-16
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：
  - 二级地图方向继承已能跟随 `RoadMask / RiverMask / CliffMask`，但同一类方向在局部沙盘内仍是“各自朝向各自的焦点”，多方向时容易出现分散、折断感；
  - 入口主方向仍依赖固定偏好顺序，遇到多方向时会出现“偏向左侧”的视觉惯性，继承不够自然。
- 证据（数据/玩家反馈）：
  - 本轮需求明确提出“继续让方向继承更自然”。

## 改动内容

- 改什么：
  - 将方向继承从“单方向优先”改为“方向向量合成”，多方向时先合成主轴再落点；
  - 对 `Road / River / Ridge` 引入“共享焦点 + 贯通对向”的方向收口：对向成对时生成穿越线，其余多向时汇合到同一焦点；
  - 入口方向与局部路径使用同一套合成方向逻辑，减少偏向固定方位的惯性。
- 不改什么：
  - 不新增美术素材与 UI 组件；
  - 不改二级地图的类型、尺寸、站点进入链与左侧检视逻辑；
  - 不新增战斗/经营等专属玩法。
- 影响系统：
  - `CountyIdle/scripts/systems/WorldSiteLocalMapGeneratorSystem.cs`
  - `docs/02_system_specs.md`
  - `docs/05_feature_inventory.md`
  - `docs/08_development_list.md`

## 预期结果

- 预期提升指标：
  - 多方向道路/水体/高差在局部沙盘内更像“同一条主轴或汇合节点”，减少割裂感；
  - 入口方向与世界格方向更一致，不再明显偏向固定侧；
  - 仍保持 deterministic（同一世界格生成结果稳定）。
- 可接受副作用：
  - 局部沙盘的路径/水体布局会与旧版略有差异，需要重新抽查观感。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 手动抽查世界图含 `道路 / 河流 / 山脊` 的格子进入二级地图，确认方向继承与入口更自然。
- 观察周期：
  - 本轮开发后立即验证 + 下一轮 Godot 运行烟测。
- 成功判定阈值：
  - build 通过；
  - 多方向格子的局部地图出现“贯通/汇合”视觉，不再多条分散短线。

## 回滚条件

- 触发条件：
  - 方向继承导致局部沙盘明显违背世界格方向，或入口方向与道路/河流出现明显冲突。
- 回滚步骤：
  - 回退到旧的“逐方向各自焦点 + 固定偏好入口”逻辑；
  - 保留方向合成与对向判定工具方法，等待下一轮再接回。

# CP-20260318：弟子修炼卷接入差事优势联动

## 提案信息

- 标题：弟子修炼卷接入差事优势联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：弟子修炼卷已经能读出长期火候、专精路数与个体表现差异，但这些路数若不继续影响外务候补、执事培养与具体内务补位，就仍停留在“看起来不同”，还没有真正变成“用起来不同”。
- 证据（数据/玩家反馈）：DL-088 已连续接入长期成长、履历回看、个体表现联动与专精差异化联动，下一步自然是让玩家看到“这名弟子的修炼方向会让他更适合哪类职责”。

## 改动内容

- 改什么：
  - 让培养路数继续参与 `外务候补` 前列筛选。
  - 让培养路数继续参与 `执事培养` 候补评分与具体内务补位执行修正。
  - 在弟子谱、修炼卷与指令反馈中补上“差事相性”描述。
  - 在任务详情与探险结果日志中继续回显“当前路数如何影响这条职责”。
- 不改什么：
  - 暂不新增新的永久属性字段。
  - 暂不把差事优势扩成复杂职业树或专属战斗技能。
  - 暂不改现有主岗位分配与 `GameState` 存档结构。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DiscipleDirectiveRules`
  - `DiscipleDirectiveSystem`
  - `DisciplePanel / CultivationPanel`

## 预期结果

- 预期提升指标：
  - 玩家能直接看到“功法路数更适合外务 / 巡检”“技艺路数更适合工坊 / 执事”“静修路数更适合长线值守”等差异。
  - 修炼卷从“养成描述”继续变成“轻量职责分流系统”。
  - 差事优势只做轻量加成，不替代原有岗位基础与治理策略。
- 可接受副作用：
  - 指令与详情文案会继续变长。
  - 若加成控制不好，可能挤压原有岗位/指令的基础差异。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 检查外务候补 / 执事培养说明，确认会显示差事相性与路线批注
  - 检查同一类候补弟子在不同培养路线下，外务/执事相关修正会产生轻量差异
- 观察周期：单次开发验证先看 6-12 次时辰结算与若干次指令切换
- 成功判定阈值：
  - 不同修炼路线能稳定影响重点差事链路
  - 文案能解释“为什么这个人更适合这条职责”
  - 不破坏旧存档兼容与现有治理主循环

## 回滚条件

- 触发条件：
  - 差事优势导致外务或内务修正明显偏强
  - UI/日志文本过长影响阅读
  - 指令候补排序与玩家预期严重背离
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的差事优势评分/修正辅助
  - 回退 `DiscipleDirectiveRules` 中的额外候补评分与执行修正
  - 回退弟子谱 / 修炼卷 / 指令日志中的差事相性文案

# CP-20260318：弟子修炼卷接入专精差异化联动

## 提案信息

- 标题：弟子修炼卷接入专精差异化联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：修炼卷已经能记录“安排 -> 收益 -> 火候 -> 履历 -> 个体表现”的闭环，但不同修炼路线的弟子仍然不够好辨认，玩家很难一眼看出某名弟子更偏功法、技艺、静修还是根基。
- 证据（数据/玩家反馈）：DL-088 已连续接入长期成长、履历回看与个体表现联动，下一步自然是把这些长期火候再归纳成更直观的培养路数，让弟子谱和修炼卷真正读出“这人是怎么被练出来的”。

## 改动内容

- 改什么：
  - 根据四类长期火候的主导项，归纳弟子的培养路数摘要。
  - 为 `根基磨砺 / 功法火候 / 技艺手感 / 静修积气` 分别生成对应的路数批语。
  - 在弟子谱与修炼卷同步展示“培养路数 / 路数批注”。
- 不改什么：
  - 暂不新增永久成长字段。
  - 暂不做复杂分支树或专属技能树。
  - 暂不改变现有时辰结算收益与个体表现联动系数。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DisciplePanel`
  - `CultivationPanel`

## 预期结果

- 预期提升指标：
  - 玩家能更快区分“悟性/战修偏盛”“匠艺/执行见长”“心境/气血更稳”“执行/气血更稳”等不同培养结果。
  - 修炼卷从“记录火候”进一步升级为“能读培养路线”的轻量养成界面。
  - 弟子谱的文字反馈与修炼卷状态展示保持同口径。
- 可接受副作用：
  - 详情页信息量会继续上涨，需要留意可读性。
  - 当前仍是轻量专精归纳，不代表已经进入复杂分支成长。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 对比不同主导火候的弟子，确认弟子谱与修炼卷中的“培养路数 / 路数批注”会同步变化
  - 确认火候较浅时会回落为“尚在积累”而非误判具体路线
- 观察周期：单次开发验证先看 6-12 次时辰结算后的差异
- 成功判定阈值：
  - 不同路线的弟子能被稳定地区分
  - 路数摘要与路数批语在弟子谱 / 修炼卷口径一致
  - 不破坏旧存档兼容与当前结算链路

## 回滚条件

- 触发条件：
  - 路数文本过于密集导致详情页难读
  - 路数归纳与实际火候方向明显不符
  - 新增展示影响旧档兼容或卷册稳定性
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的专精路数摘要/批语构建
  - 回退弟子谱与修炼卷中的专精展示文本
  - 保留修炼安排、时辰结算、长期成长、履历与个体表现联动链路

# CP-20260318：弟子修炼卷接入感悟札记联动

## 提案信息

- 标题：弟子修炼卷接入感悟札记联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：修炼路线已经能影响个体表现、重点差事与任务/探险反馈，但如果缺少更具修仙味道的个人感悟记录，玩家仍然较难从情境上感受到“这个弟子真的在被长期培养”。
- 证据（数据/玩家反馈）：DL-088 已把修炼卷推进到“有火候、有履历、有差事适配”的阶段，下一步自然是为成熟路线补上专属感悟札记，让长期培养结果在近闻与卷册里更有生命力。

## 改动内容

- 改什么：
  - 当弟子主导火候达到初段后，按稳定节律生成专属修炼札记/感悟。
  - 札记同时写入主界面近闻日志与弟子个人修炼履历。
  - 见闻报表卷可继续按现有日志链路读到这些札记。
- 不改什么：
  - 暂不新增独立复杂事件树。
  - 暂不新增新的存档字段或事件队列。
  - 暂不把札记做成可点击分支选择。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DiscipleCultivationSettlementSystem`
  - `SectChronicleRules`

## 预期结果

- 预期提升指标：
  - 玩家能在近闻与弟子履历中读到“这名弟子在这条路上悟到了什么”。
  - 修炼路线的差异不只体现在数值和岗位，也体现在氛围化反馈上。
  - 札记保持轻量、偶发，不淹没主日志。
- 可接受副作用：
  - 日志中会出现更多修炼相关文本。
  - 若触发过密，可能影响近闻阅读节奏。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 观察若干次时辰结算，确认成熟路数会偶发产出“修炼札记”
  - 检查弟子个人履历与主界面近闻是否都能看到同一条札记
- 观察周期：单次开发验证先看 8-16 次时辰结算
- 成功判定阈值：
  - 札记触发频率轻量可读
  - 不同路线札记内容有明显差异
  - 不破坏现有结算与日志链路

## 回滚条件

- 触发条件：
  - 札记触发过于频繁，冲淡主要结算日志
  - 不同路线札记差异不足
  - 见闻分类与履历回看出现混乱
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的札记构建逻辑
  - 回退 `DiscipleCultivationSettlementSystem` 中的札记写入
  - 回退 `SectChronicleRules` 中的相关分类扩展

# CP-20260318：弟子修炼卷接入感悟机缘联动

## 提案信息

- 标题：弟子修炼卷接入感悟机缘联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：DL-088 已经能产出修炼札记，但札记仍以氛围文本为主；玩家能“看到感悟”，却还不够容易感知“这次感悟带来了什么”。
- 证据（数据/玩家反馈）：当前修炼卷已经具备长期火候、路数分化、差事优势与札记回看，最自然的下一步就是让札记进一步结出一缕可见机缘，把路线差异从文本感受推进到轻量收益反馈。

## 改动内容

- 改什么：
  - 当弟子的修炼札记触发时，按主导路数结出轻量专属机缘。
  - 机缘与札记共用同一次触发，不额外增加复杂事件队列。
  - 机缘文本同时写入主界面近闻日志与弟子个人修炼履历。
  - 弟子谱 / 修炼卷额外显示“最近感悟”，让玩家在卷内也能看到最近一次札记/机缘。
- 不改什么：
  - 暂不新增可点击选项事件。
  - 暂不引入新的持久化字段。
  - 暂不把机缘扩展成复杂分支剧情链。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DiscipleCultivationSettlementSystem`
  - `DisciplePanel`
  - `CultivationPanel`

## 预期结果

- 预期提升指标：
  - 玩家能在一条札记里同时看到“悟到了什么”和“得到了什么”。
  - 四条培养路线将产生更清晰的个性化余泽：稳根记功、法悟添研、技成熟器、静修安众。
  - 修炼卷与弟子谱会更像培养卷册，而不是单纯的安排开关页。
- 可接受副作用：
  - 修炼相关文本会更长。
  - 若机缘奖励过重，可能稀释小时结算主链节奏，因此需要严格保持轻量。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 观察若干次时辰结算，确认札记触发时会附带机缘文本
  - 检查弟子谱 / 修炼卷能读取最近感悟
  - 确认机缘奖励数值轻量，未压过主修折算收益
- 观察周期：单次开发验证先看 8-16 次时辰结算
- 成功判定阈值：
  - 机缘文本与主导路数明显对应
  - 日志可读，不显著淹没主结算信息
  - 收益轻量但可被玩家直观看到

## 回滚条件

- 触发条件：
  - 札记/机缘文案过密，影响卷册与近闻阅读
  - 机缘收益过大，压过原有修炼折算
  - 卷内“最近感悟”展示与履历记录出现口径不一致
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的机缘解析逻辑
  - 回退 `DiscipleCultivationSettlementSystem` 中的机缘收益挂载
  - 回退 `DisciplePanel` / `CultivationPanel` 中的“最近感悟”展示

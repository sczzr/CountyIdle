# CP-20260318：弟子修炼卷接入专修分支成长联动

## 提案信息

- 标题：弟子修炼卷接入专修分支成长联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：DL-088 已能把弟子练出四条主导路数，但同一路数内部仍显得偏粗；例如两个都走 `功法火候` 的弟子，玩家还缺少“一个更像外务锋线、一个更像讲法推演”的读谱差异。
- 证据（数据/玩家反馈）：修炼卷已经具备长期火候、路数批语、差事优势与札记/机缘，下一步最自然的深化是让“主导火候 + 次强火候”共同决定更细的专修偏锋。

## 改动内容

- 改什么：
  - 当主导火候形成初段后，结合次强火候推导专修分支。
  - 专修分支同步显示在弟子谱 / 修炼卷中，并提供分支批注。
  - 任务详情、差事说明与相关规则叙述会回显当前专修分支。
  - 专修分支对外务候补、执事培养与具体内务条目提供更细一层的轻量修正。
- 不改什么：
  - 暂不新增新的持久化字段。
  - 暂不做完整分支树 UI。
  - 暂不把分支做成玩家主动加点或选择。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DisciplePanel`
  - `CultivationPanel`
  - `DiscipleDirectiveRules`
  - `SectTaskRules`

## 预期结果

- 预期提升指标：
  - 同一路数的弟子会进一步显出“偏哪一脉”。
  - 玩家在读弟子谱时，更容易把培养方案与差事安排对上。
  - 任务详情 / 指令说明不再只显示大类路数，而能读出更细的培养偏锋。
- 可接受副作用：
  - 文案会变长。
  - 由于分支由已有火候推导，部分弟子在早期会显示“分支未定”。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 检查弟子谱 / 修炼卷是否能显示专修分支与分支批注
  - 检查差事说明 / 任务叙述是否开始回显当前专修分支
  - 对比外务候补 / 执事补位结果，确认分支会提供轻量但可感知的偏向
- 观察周期：单次开发验证先看 8-16 次时辰结算与若干条任务描述
- 成功判定阈值：
  - 同一路数内部可读出明显分化
  - 分支修正轻量，不压过主导路数本身
  - 不新增存档迁移成本

## 回滚条件

- 触发条件：
  - 分支文案过密，卷内辨识度反而下降
  - 分支修正过强，影响原有路数平衡
  - 任务叙述与卷内显示口径不一致
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的分支解析与分支修正
  - 回退 `DisciplePanel` / `CultivationPanel` 中的分支展示
  - 保留已有培养路数、札记/机缘与基础差事优势链路

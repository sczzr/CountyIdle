# 改动提案：建筑落地可视化（山门图建筑显影）

## 提案信息

- 标题：建筑落地可视化（山门图建筑显影）
- 日期：2026-03-16
- 提案人：Codex
- 变更级别：L2 机制

## 改动背景

- 当前问题：建造建筑后缺少地图侧的可视反馈，玩家难以确认扩建成果。
- 证据（数据/玩家反馈）：试玩流程中“建造”反馈主要依赖日志，缺少即时空间反馈。

## 改动内容

- 改什么：山门图根据产业建筑数量生成对应锚点建筑显影，并在建造后刷新显示。
- 不改什么：建造成本、结算规则、存档结构、院域坊局规则。
- 影响系统：`TownMapGeneratorSystem`、`CountyTownMapViewSystem`、`Main` 地图刷新链路。

## 预期结果

- 预期提升指标：建造行为反馈更直观，扩建节奏更易感知。
- 可接受副作用：地图建筑点位增多，选中锚点需要更多定位。

## 验证计划

- 验证方式：连续建造多次产业建筑，确认地图出现新增建筑显影。
- 观察周期：单次运行内完成 3~5 次建造。
- 成功判定阈值：建造后 1 次 UI 刷新内出现新增建筑显影。

## 回滚条件

- 触发条件：建筑显影导致地图可读性显著下降或影响交互。
- 回滚步骤：移除建筑数量映射逻辑，恢复原固定锚点生成。

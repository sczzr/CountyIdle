# CP-20260318：弟子修炼卷接入个体表现联动

## 提案信息

- 标题：弟子修炼卷接入个体表现联动
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：修炼卷已能带来聚合收益、长期火候与履历回看，但这些积累若不继续反映到弟子个体表现，就仍像“记账条”，缺少真正的培养反馈。
- 证据（数据/玩家反馈）：DL-088 当前已经形成“安排 -> 收益 -> 火候 -> 履历”链路，下一步自然是让火候温和反哺弟子表现，让玩家感到“这个人被练出来了”。 

## 改动内容

- 改什么：
  - 根据长期火候对弟子派生表现做温和联动。
  - `根基磨砺` 温和反哺 `执行 / 气血 / 战修`
  - `功法火候` 温和反哺 `悟性 / 战修`
  - `技艺手感` 温和反哺 `匠艺 / 执行 / 贡献`
  - `静修积气` 温和反哺 `心境 / 气血`
  - 弟子谱与修炼卷同步展示“火候反哺”摘要。
- 不改什么：
  - 暂不新增永久基础属性字段。
  - 暂不做复杂分支成长树。
  - 暂不让火候直接覆写宗门主循环的主收益结构。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DiscipleRosterSystem`
  - `DisciplePanel / CultivationPanel`

## 预期结果

- 预期提升指标：
  - 玩家能在弟子谱中直接看到“练功后这个人变得更稳 / 更能战 / 更擅工”的反馈。
  - 修炼卷从“培养记录”进一步变成“轻量养成系统”。
  - 反馈强度温和，不替代原有岗位与治理分工。
- 可接受副作用：
  - 部分派生评语会比过去略强，需要留意数值是否挤压原有差异。
  - 文本中会增加“火候反哺”说明，详情页信息量继续上涨。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 对比修炼火候提升前后的弟子谱详情，确认悟性/匠艺/执行/心境/战修等反馈会变化
  - 确认修炼卷与弟子谱看到的“火候反哺”摘要一致
- 观察周期：单次开发验证先看 6-12 次时辰结算
- 成功判定阈值：
  - 火候反哺可见但不过强
  - 弟子详情文本与派生表现能稳定联动
  - 不破坏现有主循环与旧存档兼容

## 回滚条件

- 触发条件：
  - 火候联动导致弟子派生数值明显偏强
  - 详情文案过长影响可读性
  - 旧档兼容或 roster 生成链受损
- 回滚步骤：
  - 移除 `DiscipleCultivationRules` 中的个体表现联动折算
  - 回退 `DiscipleRosterSystem` 中的联动加成
  - 保留修炼安排、聚合收益、长期成长与履历链路

# CP-20260318：弟子修炼卷接入功法技艺专精映照

## 提案信息

- 标题：弟子修炼卷接入功法技艺专精映照
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：DL-088 已能形成培养路数与专修分支，但弟子谱里的 `功法 / 主修技艺 / 辅修技艺` 栏位仍偏泛称，玩家还不够容易从这些核心标签上直接感到“这个人练偏到了哪一脉”。
- 证据（数据/玩家反馈）：当前卷册已经能读出分支批注与差事相性，最自然的下一步是把分支直接映照进功法技艺称谓，并在分支成形时留下明确履历。

## 改动内容

- 改什么：
  - 根据当前专修分支，映照更明确的功法偏锋、主修技艺与辅修技艺称谓。
  - 在弟子谱 / 修炼卷中显式展示这些专精称谓。
  - 当专修分支首次成形或发生转向时，补记一条专名成形履历。
  - 让这些专精称谓继续回显到弟子谱详录与相关叙述中。
- 不改什么：
  - 暂不新增独立技能树 UI。
  - 暂不新增新的持久化字段。
  - 暂不做玩家主动选择分支或手动加点。
- 影响系统：
  - `DiscipleCultivationRules`
  - `DiscipleCultivationSettlementSystem`
  - `DisciplePanel`
  - `CultivationPanel`

## 预期结果

- 预期提升指标：
  - 玩家看 `功法 / 技艺` 标签时，就能直接感知培养偏锋。
  - 分支成长不再只存在于说明段落，而会进入弟子最核心的身份标签。
  - 分支成形时拥有更强的“养成节点”感。
- 可接受副作用：
  - 标签文本会变长。
  - 若映照名称过多，需注意卷面阅读密度。

## 验证计划

- 验证方式：
  - `dotnet build .\Finally.sln`
  - 检查弟子谱的功法 / 主修技艺 / 辅修技艺是否会随专修分支变化
  - 检查修炼卷 / 弟子谱中是否能读到分支成形或转向的履历
  - 检查当前分支仍与既有差事优势口径一致
- 观察周期：单次开发验证先看 8-16 次时辰结算与若干名弟子详情
- 成功判定阈值：
  - 同一路数弟子的功法/技艺标签能继续拉开差异
  - 履历能记录分支成形节点
  - 不增加存档兼容成本

## 回滚条件

- 触发条件：
  - 功法/技艺专精称谓过密或过长，影响卷册阅读
  - 分支成形履历触发过频
  - 功法/技艺映照与分支/差事口径不一致
- 回滚步骤：
  - 回退 `DiscipleCultivationRules` 中的专精称谓映照与履历钩子
  - 回退 `DiscipleCultivationSettlementSystem` 中的分支成形履历写入
  - 回退 `DisciplePanel` / `CultivationPanel` 中的专精展示

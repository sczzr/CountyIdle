# 改动提案：建筑落地持久化（山门图落点存档）

## 提案信息

- 标题：建筑落地持久化（山门图落点存档）
- 日期：2026-03-16
- 提案人：Codex
- 变更级别：L2 机制

## 改动背景

- 当前问题：建筑落点仅存于运行期内存，读档后无法保持原地块显示。
- 证据（数据/玩家反馈）：试玩流程中多次建造后读档会出现落点重置。

## 改动内容

- 改什么：将建筑落点写入 `GameState` 并随存档持久化，读档后复原锚点显影。
- 不改什么：建筑成本、结算节奏、地图种子/布局逻辑。
- 影响系统：`GameState`、`SaveSystem`、`CountyTownMapViewSystem`、`Main` 建造入口。

## 预期结果

- 预期提升指标：读档后建筑显影位置保持一致。
- 可接受副作用：存档体积小幅增加。

## 验证计划

- 验证方式：建造 3~5 座产业建筑 → 存档 → 读档 → 检查落点一致性。
- 观察周期：单次运行内完成。
- 成功判定阈值：读档后至少 3 处建筑落点与存档前一致。

## 回滚条件

- 触发条件：落点持久化导致读档失败或地图显影异常。
- 回滚步骤：移除落点字段与复原逻辑，回退到仅按数量显影。

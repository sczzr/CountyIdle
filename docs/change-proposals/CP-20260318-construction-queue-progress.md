# 改动提案：文明式营建卷队列与时辰进度接入

## 提案信息

- 标题：文明式营建卷队列与时辰进度接入
- 日期：2026-03-18
- 提案人：Codex
- 变更级别：`L2 机制`

## 改动背景

- 当前问题：营建卷已搭建，但建造仍为即时完成，队列/进度区仅占位，玩家无法感知排队与时辰推进节奏。
- 证据（数据/玩家反馈）：DL-090 功能包状态与功能卡 DoD 明确“队列/进度与时辰结算推进”仍缺口。

## 改动内容

- 改什么：
  - 引入 `ConstructionQueueItem` 营建队列条目，建造动作进入队列并按时辰结算推进。
  - 建筑完工后更新建筑数量，并生成“待落点”记录，由主界面在山门图落点并回写。
  - 队列支持撤销/停工：未开工可撤销并退回消耗，已开工仅停工不退费。
- 不改什么：
  - 不改建造成本公式、建筑收益与人口/职司联动规则。
  - 不引入纯建筑摆放玩法或独立建造战役。
- 影响系统：
  - `IndustrySystem`、`GameLoop`、`GameState`、`ConstructionPanel`、`Main` 山门图落点链路。

## 预期结果

- 预期提升指标：
  - 营建反馈可视化：队列/进度明确可读。
  - 建造节奏：进入时辰结算节奏而非瞬时完成。
- 可接受副作用：
  - 建造完成存在 1-2 时辰延迟。

## 验证计划

- 验证方式：
  - 进入营建卷建造 2-3 项，观察队列与时辰推进。
  - 在队列中撤销排队与停工，核对资源回退与日志。
  - 完工后检查山门图落点与日志。
- 观察周期：1~2 次时辰结算。
- 成功判定阈值：
  - 队列与进度可读、完工日志出现、落点成功写入。

## 回滚条件

- 触发条件：
  - 营建队列导致建造无法完成或资源异常回退。
- 回滚步骤：
  - 恢复即时建造逻辑，移除队列字段与相关 UI。
